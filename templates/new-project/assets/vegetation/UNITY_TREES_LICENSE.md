# Modelos de vegetação — Unity Technologies "Terrain Assets"

Os `.glb` neste diretório (alder, mimosa, scotspine-a/b, sycamore, thintree, bush5/7)
foram **exportados via glTFast** a partir dos modelos do pacote **"Terrain Assets" da
Unity Technologies** (distribuídos dentro do *Tom's Terrain Tools*). Geometria + texturas
embutidas no `.glb`.

- Fonte: https://assetstore.unity.com/packages/3d/vegetation/terrain-assets-6

**Licença:** assets da Unity Technologies, sob a **Unity Asset Store EULA** (≠ MIT/CC0).
Inclusão neste repositório feita por decisão explícita do dono do projeto, que assumiu a
responsabilidade pelas licenças.

Use no nó `vegetation` (`model: "assets/vegetation/scotspine-a.glb"`) ou pelo seletor
"Modelo" do pincel de vegetação no editor.
