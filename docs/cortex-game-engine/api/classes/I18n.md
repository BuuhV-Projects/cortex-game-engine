# Class: I18n

Defined in: [.claude/worktrees/feat-input-rebind/src/i18n/I18n.ts:99](https://github.com/BuuhV-Projects/cortex-game-engine/blob/main/src/i18n/I18n.ts#L99)

Carrega e consulta traduções. Use a instância global [i18n](../variables/i18n.md) (e o atalho
[t](../functions/t.md)) — ou crie a sua se precisar de dois conjuntos independentes.

Resolução de `t(chave)`: idioma atual → idioma de fallback → a própria chave
(e loga em `debug('i18n', ...)` quando falta).

### loadAuto()

Defined in: [.claude/worktrees/feat-input-rebind/src/i18n/I18n.ts:137](https://github.com/BuuhV-Projects/cortex-game-engine/blob/main/src/i18n/I18n.ts#L137)

Primeira abertura (sem idioma salvo): detecta o idioma do SO e carrega o
primeiro disponível — tenta o código exato (`pt-BR`), depois só a língua
(`pt`) e por fim o `default`. As chaves que faltarem caem pro `default`
(ou pro `fallback`, se informado). Retorna o código escolhido — persista
no `config.ini` se quiser fixar a escolha.
