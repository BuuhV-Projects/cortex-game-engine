Código com IA

Um agente IA mora dentro da IDE: conversa com o seu projeto, cria componentes ECS, escreve sistemas, ajusta cenas. Com sandbox no projeto ativo e aprovação por ferramenta.

🎨

Modelos 3D com IA

Descreva o asset, a IA gera o script Blender e exporta o .glb pronto pra usar na cena. Sem sair da IDE.

💻

Jogos para desktop

TypeScript + Three.js + ECS. Preview ao vivo durante o desenvolvimento. Um clique pra empacotar como instalador Windows distribuível.

Tudo num lugar só

Editor Monaco, terminal embutido, file tree com drag-and-drop, preview hot-reload, chat IA na sidebar e gerador de instalador. Você abre a IDE, descreve o que quer e sai com um .exe jogável.

Open source

Construído à mostra. Pull requests são bem-vindos.

Todo o engine, a IDE, o agente IA e este site vivem num único repositório aberto. Achou um bug, viu como melhorar uma feature ou quer estender o engine com uma capacidade nova? Abra um PR — ou um issue, se quiser discutir antes.
